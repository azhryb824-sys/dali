# تطبيق دالي لسطح المكتب

تطبيق Electron لنظام Windows x64 يعرض واجهة النظام نفسها ويضيف تخزينًا محليًا مشفرًا وطابور مزامنة كل 20 ثانية.

## السياسة غير المتصلة

- يسمح بإنشاء المسودات والعمليات التشغيلية غير النهائية عند انقطاع الاتصال.
- يمنع الاعتماد، السداد، الترحيل، تفعيل العقود، وإجراءات الإغلاق النهائية دون اتصال.
- تحفظ استجابات القراءة محليًا بصورة مشفرة.
- تحفظ العمليات غير الحساسة المتعثرة في طابور مشفر، وتُرسل بالترتيب عند عودة الاتصال.
- يرسل كل طلب مع مفتاح idempotency لمنع التنفيذ المكرر.
- التعارضات لا تُكتب فوق بيانات الخادم، بل تُعزل للمراجعة.

## البناء على Windows

```powershell
cd desktop
npm ci
npm run build:windows
```

الملف الناتج داخل `desktop/dist`.
