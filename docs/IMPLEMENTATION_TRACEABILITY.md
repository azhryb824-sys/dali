# سجل تنفيذ توسعة دالي: المملكة والمقاولات

آخر تحقق: 20 أغسطس 2026

## تصحيح نطاق التنفيذ

كان الإصدار السابق يصف صفحة عامة واحدة وأربع تبويبات إدارية بأنها «قطاع مقاولات مكتمل». صححت هذه الدفعة ذلك الخلل: المقاولات الآن قسم عام متعدد الصفحات، وفي البوابة دورة تشغيلية تغطي مراحل ما قبل التعاقد والتنفيذ الميداني والتجاري والتسليم، وليست مجرد لوحة فرص ومشروعات.

## مصفوفة التتبع

| مطلب الوثيقة | التنفيذ | الدليل |
|---|---|---|
| قسم مقاولات عام مستقل | نظرة عامة، تخصصات، منهجية، جودة وسلامة، مشروعات، مناطق، وطلب دراسة | `app/construction/**` |
| SEO وطني غير آلي | Metadata وcanonical وروابط HTML وSitemap لكل واجهة، ونصوص تشرح القيود ولا تدعي فروعاً أو مشروعات | `app/sitemap.ts` وواجهات القسم |
| فرص ومناقصات | إنشاء الفرصة، مراحل Pipeline، بحث، موعد العرض، المسؤول، الإشعارات والتدقيق | `construction_opportunities` وAPI البوابة |
| المعاينات | سجل معاينة مرتبط بالفرصة أو المشروع ومسؤول وموعد وحالة | `construction_records.type=survey` |
| التقدير وBOQ | سجلات مستقلة وبنود علائقية كمية ووحدة وسعر وإجمالي، لا حقل JSON واحد | `construction_records` و`construction_record_lines` |
| عقود المقاولات | سجل عقد مستقل عن عقود العمالة، مرتبط بالفرصة أو المشروع، ذو مراجعات وحالات | `recordType=contract` |
| المشروعات ومراكز التكلفة | تحويل الفرصة الفائزة إلى مشروع ومركز تكلفة ذرياً | `construction_projects` و`cost_centers` |
| WBS والتخطيط والمخاطر | سجلات WBS ببنود تفصيلية وسجل مخاطر ومسؤوليات ومواعيد | `recordType=wbs/risk` |
| يوميات الموقع | سجل يومي مستقل قابل للربط بالمشروع والتدقيق | `recordType=daily_log` |
| الوثائق وRFI وSubmittal | أنواع مستقلة وحالات مراجعة واعتماد وإجابة وإغلاق | `recordType=document/rfi/submittal` |
| الجودة والسلامة | فحوص وعدم مطابقة NCR وسجلات سلامة مع أولوية وحالة ومسؤول | `recordType=inspection/ncr/safety` |
| مشتريات المشروع ومقاولو الباطن | سجلات مستقلة مرتبطة بالمشروع ودورة حالة من الطلب حتى الاستلام أو الإغلاق | `recordType=procurement/subcontract` |
| أوامر التغيير | سجل تغيير ذو قيمة وبنود وتدقيق وحالات تسعير ومراجعة واعتماد | `recordType=change_order` |
| المستخلصات والاحتجاز | سجل مستخلص ذو قيمة ونسبة احتجاز وبنود وحالات اعتماد وفوترة وسداد | `recordType=payment_certificate` |
| التسليم والضمان | سجل تسليم وإقفال مرتبط بالمشروع | `recordType=handover` |
| التغطية الوطنية | 13 منطقة ومدن وقدرة خدمة وحالة إتاحة واعتماد نشر لا يمنحه إلا مدير النظام | `service_regions/cities/coverage` |
| واجهتا خدماتنا ومناطق الخدمة | محتوى إنتاجي يوضح المسارات الثلاثة، ويعرض مناطق المملكة الثلاث عشرة، ويؤكد خدمة المدن دون ادعاء فروع غير موجودة | `app/services/page.tsx` و`app/locations/page.tsx` |
| الأدوار والصلاحيات الدقيقة | 20 دوراً وظيفياً مع نطاق قطاع/منطقة/مدينة/مشروع وحدود تنفيذ واعتماد وفترة صلاحية | `portal_access_scopes` و`lib/access-policy.ts` وواجهة إدارة النطاقات |
| فصل الواجبات | منع منشئ السجل من اعتماده، إلا باستثناء صريح مسجل، مع حدود مالية مستقلة للتنفيذ والاعتماد | API المقاولات و`can_approve_own` |
| وثائق المقاولات PDF | تنزيل سجل مقاولات مهني بالهوية والخط العربي والختم والتوقيع والبنود بعد التحقق من النطاق والصلاحية | `/api/portal/construction/pdf` |
| الختم والتوقيع على Render | تخزين PostgreSQL دائم كمسار احتياطي عند غياب Object Storage bindings، بدلاً من نظام ملفات الحاوية المؤقت | `lib/runtime-env.ts` |
| البحث الشامل | الفرص والمشروعات وجميع سجلات المقاولات الجديدة | `/api/portal/search` |
| التنبيهات والتدقيق | إشعار وOutbox وتدقيق بعد الأحداث الناجحة وتاريخ حالة | API المقاولات و`lib/portal-notifications.ts` |
| سلامة البيانات | قيود وفهارس وoptimistic locking وRLS ومنع Data API العام | migration `0004` وما قبلها |

## الواجهات الإدارية المنفذة

1. لوحة محفظة المقاولات.
2. الفرص والمناقصات.
3. المعاينات والتقدير وBOQ وعقود المقاولات.
4. قائمة المشروعات ومراكز التكلفة.
5. التخطيط وWBS والمخاطر.
6. الموقع ويوميات التنفيذ.
7. الوثائق وRFI واعتمادات المواد.
8. الجودة والفحوص وعدم المطابقة والسلامة.
9. مشتريات المشروع ومقاولو الباطن.
10. أوامر التغيير والمستخلصات والاحتجاز.
11. التسليم والضمان.
12. تغطية مناطق ومدن المملكة.
13. إدارة الأدوار الوظيفية ونطاقاتها الجغرافية والمشروعاتية والمالية.
14. تنزيل مستندات سجلات المقاولات بصيغة PDF ممهورة بالختم والتوقيع.

## ضوابط ثابتة

- لا يُعاد تصنيف عقد عمالة كمقاولات.
- لا تنشر صفحة مدينة قالبية؛ صفحة المنطقة الحالية تشرح مسار الخدمة ولا تدعي وجود فرع.
- لا تنشر دراسة حالة قبل اعتماد حق النشر والبيانات.
- لا تُخترع تراخيص أو تصنيفات أو أرقام مشروعات.
- العمليات المالية المرحلة تبقى خاضعة لقواعد القيد والعكس والإقفال في النواة المالية.

## بوابات القبول

- `npm run typecheck`
- `npm run lint`
- `npm run build`
- `node --test tests/*.test.mjs`
- تطبيق migration `0004` و`0005` قبل تشغيل الإصدار (تم تطبيق `0005` والتحقق من RLS ومنع وصول Data API العام في قاعدة الإنتاج).
- فحص المسارات العامة السبعة وcanonical وSitemap على نطاق الإنتاج.
- اختبار إنشاء سجل من كل مجموعة، وإضافة بند BOQ، وتغيير الحالة تحت مستخدم مصرح وغير مصرح.
