# إصلاح مشاركة الملفات في Windows — 20 سبتمبر 2026

رسالة تعذر فتح نافذة Windows القديمة كانت تجمع فشل تنزيل الملف وفشل تشغيل المكوّن. لذلك لا تكفي الرسالة وحدها لإثبات السبب على جهاز المستخدم.

## التغييرات

- تنزيل مرفقات تطبيقي سطح المكتب عبر جلسة Electron نفسها لدعم إعدادات اتصال النظام، مع منع التحويل إلى روابط أخرى والإبقاء على حدود الحجم والتحقق من اكتمال الملف.
- منع تضارب أسماء المرفقات، وأسماء أجهزة Windows المحجوزة، وأسماء ملفات التحكم؛ حذف التنزيل غير المكتمل وإظهار سبب قابل للتصرف.
- تشغيل نافذة المشاركة بعد بدء حلقة رسائل نافذتها المرئية، والتقاط أخطاء تجهيز البيانات داخل الحدث، والتحقق من مسارات Windows دون الاعتماد على المقارنة النصية الحساسة لحالة الأحرف.
- خيار «نسخ الملفات وفتح واتساب» في مشاركة العروض والفواتير والعقود والملفات القانونية: ينسخ الملفات الفعلية بصيغة CF_HDROP ثم يطلب فتح محادثة المستلم. يضغط المستخدم Ctrl+V ويتحقق من المرفقات ويؤكد الإرسال.
- لا تُعد عملية النسخ أو فتح النافذة تأكيدًا على إرسال الرسالة إلى العميل.
- المتصفح يرفض الملفات الناقصة والفارغة والتنزيلات التي تتجاوز الحد الفعلي، ويحافظ على استدعاء المشاركة ضمن ضغطة المستخدم.

## التحقق وحدوده

- اختبارات تنزيل فعلية إلى مجلد مؤقت على حزمتي سطح المكتب: الأسماء المتكررة والمحجوزة، انقطاع الاتصال، انتهاء الرابط، الملفات الناقصة والفارغة، تجاوز الحجم وتنظيف التنزيلات الفاشلة.
- اختبارات مسارات المتصفح وAndroid وجسر سطح المكتب وحدود الروابط وعدم اعتبار الإلغاء أو الفشل نجاحًا.
- أصبح بناء Windows ينفذ المكوّن الأصلي على ملفات PDF صالحة بأسماء عربية؛ يقرأ حزمة WinRT، ويختبر الحافظة بقارئ مستقل، ويمنع نسخ الملفات خارج المجلد المجهز. يحدث ذلك قبل إنشاء وسم الإصدار.
- يسجل اختبار Windows حالة نافذة النظام نفسها بوضوح؛ قد لا تتوفر Share Host على خادم البناء. نجاح اختبار الملفات والحافظة لا يعني اختبار واتساب على جهاز المستخدم.
- يلزم اختبار ظهور المرفقات ثم إرسالها من نسخة واتساب المثبتة لدى المستخدم. لا يوجد وصول إلى جهازه أو تأكيد استلام من عميل ضمن هذا الإصلاح.

## التثبيت

Windows 0.2.12، وmacOS Universal 1.0.5. يحتاج خيار النسخ الجديد إلى تحديث تطبيق Windows ونشر واجهة الموقع معًا. يحتفظ التطبيق بهويته وإعدادات الدخول والتحديث السابقة.
