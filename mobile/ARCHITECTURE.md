# تحليل وبنية تطبيق نظام دالي للجوال

## القرار المعماري

النظام الحالي تطبيق Next.js إداري كبير يعتمد على صلاحيات خادمية، سجل تدقيق، PostgreSQL، وتوليد مستندات. تطبيق سطح المكتب ليس نسخة أعمال مستقلة؛ هو حاوية Electron موثوقة للبوابة نفسها مع طبقة مزامنة. لذلك يستخدم تطبيق الجوال النمط نفسه عبر Capacitor بدل نسخ منطق الموارد البشرية والعقود والمالية والقضايا إلى قاعدة محلية ثانية.

هذا يحافظ على مصدر حقيقة واحد، وعلى ظهور أي تطوير جديد في سطح المكتب والجوال معًا، وعلى تطبيق RBAC والتدقيق في الخادم دائمًا.

## المكونات

| الطبقة | التنفيذ | المسؤولية |
|---|---|---|
| واجهة الأعمال | بوابة Next.js الحالية | الشاشات والنماذج والبحث والصلاحيات |
| الحاوية الأصلية | Capacitor 8 | Android وiOS وWebView موثوق |
| تعريف العميل | `DaliMobile/1` في User-Agent | تمييز الحاوية مع بقاء المصادقة إلزامية |
| التخزين المؤقت | Service Worker + IndexedDB | JSON مشفر وطابور عمليات آمنة |
| التشفير | AES-256-GCM | مفتاح Web Crypto غير قابل للاستخراج داخل حاوية التطبيق |
| المزامنة | مسار المزامنة الحالي | Cursor وتغييرات الخادم ومفاتيح منع التكرار |
| الجهاز | إضافات Capacitor الرسمية | كاميرا، ملفات، مشاركة، شبكة، إشعارات، وشاشة خصوصية |

## حدود العمل دون اتصال

يسمح بعرض استجابات JSON التي سبق فتحها وبحفظ تعديلات منخفضة المخاطر عند انقطاع الشبكة. لا تدخل العمليات التالية الطابور مطلقًا: الحذف، الاعتماد، ترحيل القيود، الدفع، إدارة المستخدمين والأدوار والنطاقات، تغيير حالات العقود الحساسة، ورفع النسخ الموقعة. يعيد الخادم فحص السياسة كذلك، لذلك لا يعتمد الأمان على كود الجهاز.

## تكافؤ الوظائف

كل وحدات البوابة الحالية متاحة: النظرة العامة، العقود والعمال، الموظفون والموارد البشرية والرواتب، المالية والمحاسبة، القضايا القانونية، الوثائق والخطابات، المشاريع، المبيعات، المحادثات، المهام، الحكومة، المستخدمون والصلاحيات، التقارير والبحث العام. الرفع يستخدم منتقي الملفات/الكاميرا الأصلي، والتنزيل يستخدم Filesystem وShare عند توفرهما.

## التوزيع

- Android: يتطلب Android Studio/SDK وJDK، ثم توقيع AAB بمفتاح الشركة.
- iOS: يتطلب macOS وXcode 26+ وحساب Apple Developer وProvisioning Profile.
- الإشعارات البعيدة تتطلب ملفات FCM/APNs الخاصة بالشركة عند الإصدار؛ لا تدخل هذه الأسرار إلى Git.
- عنوان الإنتاج مضبوط على `https://www.dally.info/portal` ولا يسمح بـHTTP أو نطاق خارجي داخل WebView.
