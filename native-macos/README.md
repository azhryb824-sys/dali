# نظام دالي الإداري الخفيف للـ macOS

تطبيق macOS أصلي مستقل مبني على `WKWebView` ومحرك WebKit الموجود في النظام. لا يضم Electron أو Chromium، ولا يستبدل نسخة Windows أو نسخة Electron القديمة، ولا يغيّر المتصفح الافتراضي أو إعدادات الجهاز.

## حدود التشغيل المقصودة

- Apple Silicon ‏(ARM64).
- macOS 13 أو أحدث، ويشمل macOS 15.7.4 على الجهاز المستهدف.
- لا يعمل عند بدء تشغيل الجهاز تلقائيًا.
- لا ينشئ خدمة خلفية أو برنامج مزامنة مستقلًا.
- ينتهي بالكامل عند إغلاق آخر نافذة.
- يستخدم ملفات تعريف ارتباط WebKit الآمنة فقط داخل حاوية التطبيق.
- لا يفتح الروابط الخارجية داخل النظام؛ يرسلها إلى المتصفح الافتراضي.
- يطلب إذن الكاميرا أو الميكروفون عند استعمال المكالمة فقط.
- يطلب من المستخدم اختيار مكان حفظ كل ملف.

## البناء

ينفذ البناء على macOS فقط:

```bash
bash native-macos/scripts/build.sh arm64
```

تُنشأ حزمة DMG وZIP داخل `native-macos/dist`.
